# 开发路线与验收清单

目标：C++17 / Qt 6 Windows 客户端与 muduo Linux 模块化单体服务端，适合展示网络、并发、可靠性和数据库能力。先验证单机正确性，再优化性能。

## P1：审查与工程整理（已验收）

- [x] 审查 Git、目录、Qt Widgets 架构、CMake 和已有功能。
- [x] 检查本机 Qt、编译器、网络/SQL 驱动和 Linux 执行环境。
- [x] 保留客户端、拆分业务协调入口、建立独立客户端 CMake。
- [x] 设置 C++17 上限与平台构建边界，不让客户端依赖服务端库。
- [x] 完成架构、协议、数据库、进度、压测与面试文档。
- [x] 生成文件树、整理资源、归档遗留 IDE 缓存（保留文件）。
- [x] 实际编译、运行数据/UI/Win32 测试与独立客户端构建。
- [x] 更新进度并列出真实通信、SQLite 等未实现项。

验收：已有聊天交互和 Snap 原生测试继续通过；Qt 客户端可单独配置；文档明确实现边界；无 C++20 依赖。

## P2：Linux 网络骨架（已验收）

- [x] 在可用的 Ubuntu 环境核对并锁定 muduo、Boost、Protobuf、GoogleTest 的版本。
- [x] 完成 Qt 无关的长度前缀编解码器和 `protocol/chat.proto`。
- [x] 建立 muduo TcpServer、连接上下文、协议校验与请求分发。
- [x] 实现有界业务线程池、任务所有权、满队列拒绝与退出语义。
- [x] 实现连接级限额、高水位处理、心跳和优雅停服。
- [x] GoogleTest 验证每个拆包边界、多帧、非法长度/版本/内容、线程池退出；真实 TCP 集成测试与 ASan/UBSan。

验收结果：Ubuntu 24.04.3 / GCC 13.3 的 Debug、Release、ASan/UBSan 均通过 3/3 CTest，共 28 个 GoogleTest；另完成三项生命周期回归各 10 轮。Windows 客户端回归 3/3 通过。仅 HELLO/PING/ECHO 诊断收发，未实现用户聊天或数据库 ACK；具体证据见 progress.md。

## P3：认证、MySQL 与消息业务

- [ ] 迁移 SQL、连接池、事务和数据库错误映射。
- [ ] 注册/登录/登出、Argon2id 密码哈希和认证限流。
- [ ] 用户资料、好友关系、单聊会话与成员权限检查。
- [ ] 消息入库、消息 ID 去重、持久化 ACK、收件箱游标。
- [ ] 在线投递、投递/已读回执、历史查询与离线同步。
- [ ] 验证重复消息、重复请求 ID、断库、提交后断线、重启补投。

验收：两用户真实消息持久化、离线补收、重试无重复记录；Redis 停止不丢关键数据。

## P4：Qt 联调

- [ ] Controller → ChatService → 异步 Qt Network → 协议模块。
- [ ] 登录/注册 UI、连接与认证状态、明确切换本地演示/真实服务器。
- [ ] 独立存储线程、Qt SQL SQLite、事务、schema 版本与旧 JSON 导入。
- [ ] UUID 消息 ID、pending/sending/persisted/delivered/read/failed 状态、重试退避。
- [ ] 会话同步、未读、离线分页、断线重连和历史搜索。
- [ ] 浅/深主题、状态反馈；协议稳定后再实现图片/文件和撤回。

验收：Windows 两实例与 Ubuntu 服务端联调；消息保存、重启、断网恢复可复现。此阶段后才能称为联网聊天客户端。

## P5：并发与可靠性

- [ ] Redis 在线状态 TTL、会话代次和热点缓存。

- [ ] 故障注入：Redis/MySQL 故障、进程终止、慢读客户端、半包长连接。
- [ ] 正确处理并发登录、旧连接迟到清理和关闭期间任务回调。
- [ ] 线程安全审计；可用平台再增加 TSan。
